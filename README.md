## 🚀 Cara Menjalankan Portofolio di Laptop

Cukup buka file `index.html` langsung di browser favorit kamu (Google Chrome, Edge, Safari):
- **Cara 1:** Double-click file `index.html`.
- **Cara 2 (Live Server di VS Code / Cursor):** Klik kanan `index.html` &rarr; *Open with Live Server*.
- **Cara 3 (Python Server):**
  ```bash
  python -m http.server 8080
  ```
  Lalu buka `http://localhost:8080` di browser.

## 📸 Cara Mengganti Foto Profil Nanti

Jika nanti kamu sudah punya foto jas formal atau foto studio baru:
1. Simpan foto barumu dengan nama `hero-francis.png` (disarankan rasio 4:5 atau crop setengah badan).
2. Letakkan file tersebut di folder `assets/images/hero-francis.png` (menimpa file lama).
3. Refresh website kamu di browser — secara otomatis foto baru akan langsung terbingkai rapi dengan efek pencahayaan dan gradient fade yang sama!

## 🌐 Cara Deploy Gratis ke Internet (Vercel / Netlify / GitHub Pages)

- **Vercel**: Cukup drag-and-drop folder ini ke [vercel.com](https://vercel.com) atau connect via GitHub repository.
- **Netlify**: Drag-and-drop folder ini ke [app.netlify.com/drop](https://app.netlify.com/drop) untuk langsung dapat link website aktif dalam 30 detik!
- **GitHub Pages**: Push repository ini ke GitHub, lalu aktifkan *Pages* dari tab *Settings* &rarr; *Pages*.
